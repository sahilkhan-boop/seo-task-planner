Google Search Console

{{ "Connected" if gsc_connected else "Not connected yet" }}

Paste the property URL below (which GSC property to sync), and sign in with Google to authorize actual data access. CTR-optimization tasks activate automatically once connected.

Used to tell branded from non-branded search queries -- both for spotting content gaps on page-2-ish pages (position 5-15), and for CTR benchmarks segmented by branded vs non-branded (e.g. a "branded_pos_1_5" benchmark) once configured. A query counts as branded if it contains any brand term, or matches the regex when one's set (spelling variants, apostrophes/hyphens, sub-brand names a plain term list can't cover well). Invalid regex is ignored, never blocks a sync.

Optional -- same idea as Search Console's own Performance-report filters. Scope task generation to (or away from) a specific URL path or query pattern, entirely optional.
